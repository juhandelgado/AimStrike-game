## 📌 Sobre o projeto

O **Aim-Strike** é um jogo de treinamento de mira em 3D inspirado em jogos de treinamento de precisão para FPS (*First-Person Shooter*).

O projeto foi desenvolvido para navegador e tem como objetivo permitir que os jogadores pratiquem sua mira, precisão e reflexos em um campo de treinamento tridimensional.

Este é um projeto de aprendizado e desenvolvimento contínuo, com possibilidades de melhorias e novos recursos no futuro.

## ✨ Funcionalidades

- 🎯 Campo de treinamento em 3D.
- 🔫 Modelos de armas em primeira pessoa.
- ⚡ Animações de armas, incluindo disparo e recarga.
- 🖱️ Controle da visão e da mira pelo mouse.
- 🎮 Interface de jogo com informações da partida.
- 🏆 Sistema de pontuação e treinamento de precisão.
- 🌐 Acesso pelo navegador, sem precisar instalar o jogo.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Utilização |
|---|---|
| HTML5 | Estrutura da página e interface. |
| CSS3 | Estilização e organização visual. |
| JavaScript | Lógica, controles e funcionamento do jogo. |

## 🎮 Como jogar

Acesse o jogo pelo link:

**[Jogar Aim-Strike](https://juhandelgado.github.io/AimStrike-game/)**

Controles principais:

| Comando | Função |
|---|---|
| Mouse | Controlar a visão e a mira. |
| Botão esquerdo do mouse | Atirar. |
| Tecla `1` | Selecionar a primeira arma. |
| Tecla `2` | Selecionar a segunda arma. |
| Tecla `R` | Recarregar a arma, quando disponível. |
| `Esc` | Liberar o controle do mouse, quando capturado. |

*Os comandos podem depender da arma selecionada e das funções habilitadas na versão atual.*

## 💻 Como executar o projeto localmente

### 1. Baixe o projeto

Clone o repositório:

```bash
git clone https://github.com/juhandelgado/AimStrike-game.git
```

Ou baixe o projeto pelo botão **Code → Download ZIP** no GitHub.

### 2. Abra no Visual Studio Code

Extraia os arquivos, abra a pasta do projeto no VS Code e confira se os arquivos e modelos 3D estão presentes.

### 3. Execute com o Live Server

Instale a extensão **Live Server** no Visual Studio Code, caso ainda não tenha instalado.

Depois, clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server**.

O jogo será aberto no navegador. É necessário ter conexão com a internet para carregar as bibliotecas externas utilizadas pelo projeto.

## 📁 Estrutura do projeto

```text
AimStrike-game/
├── index.html
├── style.css
├── script.js
├── heavy_pistol_animated.glb
├── m4_fps.glb
├── GDD_AimLabmd
└── README.md
```

- **index.html:** estrutura principal da página.
- **style.css:** estilos e aparência da interface.
- **script.js:** lógica do jogo, controles, cenário 3D e integração das armas.
- **heavy_pistol_animated.glb:** modelo 3D da pistola.
- **m4_fps.glb:** modelo 3D da M4.
- **GDD_AimLabmd:** documento de Game Design Document (GDD) do projeto.
- **README.md:** apresentação e instruções do projeto.

## 📚 Objetivo educacional

O desenvolvimento do Aim-Strike permite praticar conceitos de desenvolvimento web, programação JavaScript, renderização 3D, manipulação de modelos, animações e interação com o usuário.

Durante o desenvolvimento, foram utilizadas ferramentas de inteligência artificial, como **ChatGPT e Claude**, para auxiliar no aprendizado, na organização do código, na integração de modelos 3D e na investigação de erros.

As sugestões foram adaptadas ao projeto e testadas durante o desenvolvimento.

## 🚀 Melhorias futuras

- Novos desafios de mira e reflexo.
